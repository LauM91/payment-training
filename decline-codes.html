Quick Troubleshooting Tips

  • • If ALL cards decline with code 05 or 96: Check terminal connectivity
  • • If one specific card declines: Likely issuer/cardholder issue
  • • Codes 51, 54, 55, 61: Customer must resolve with their bank
  • • Codes 03, 12, 58: Configuration issue - contact Swedbank/Nets
  • • Code 91: May indicate issuer system outage or network problem
